# Code of Conduct

## Our standard

We expect contributors to communicate professionally and respectfully. Focus criticism on ideas and implementation, not people.

Unacceptable behavior includes harassment, discrimination, personal attacks, intimidation, deliberate disruption, and sharing private information without consent.

## Enforcement

Project maintainers may remove comments, request changes, restrict participation, or take other reasonable action when behavior violates this standard.

For sensitive concerns, use the private security/reporting channel described in `SECURITY.md` rather than posting confidential details publicly.
